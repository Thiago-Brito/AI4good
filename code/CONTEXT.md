# Code
> Projetos de software da disciplina.

Cada subpasta em `code/` deve ter:

- `README.md`: como instalar e executar.
- `CONTEXT.md`: o que o projeto faz e como mexer nele.
- `EXPERIMENTS.md`: experimentos, parametros e resultados.
- `requirements.txt`, `pyproject.toml` ou equivalente, quando houver dependencias.

Antes de alterar codigo, rode uma busca pelos usos da funcao ou classe que sera alterada.
