# Rede Neural do Zero
> Aplicacao didatica Streamlit para visualizar uma rede neural treinando.

Este projeto e o codigo inicial do trabalho. Ele pode servir como:

- demonstrador didatico;
- base de experimento;
- apoio visual para o relatorio/artigo.

## Comandos

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app_conexoes.py
```

## Cuidados

- Nao usar bibliotecas prontas de redes neurais se o objetivo for explicar a implementacao.
- Registrar mudancas experimentais em `EXPERIMENTS.md`.
- Guardar figuras e saidas em `outputs/`, nao na raiz do workspace.
